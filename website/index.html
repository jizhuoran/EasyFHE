Build

Editable CUDA development build

EasyFHE is currently built from source. The fast build flags keep the runtime focused on CUDA FHE development and avoid unused training or mobile surfaces. 

python3 setup.py clean

USE_EASYFHE_FAST_BUILD=1 \
USE_EASYFHE_FAST_INFERENCE=1 \
USE_CUDA=1 USE_DISTRIBUTED=1 USE_NCCL=1 \
USE_GLOO=0 USE_TENSORPIPE=0 USE_MPI=0 USE_UCC=0 \
USE_CUDNN=0 USE_MKLDNN=0 BUILD_TEST=0 \
BUILD_FUNCTORCH=0 USE_NINJA=1 \
CMAKE_BUILD_TYPE=Release TORCH_CUDA_ARCH_LIST=8.0 \
MAX_JOBS=24 python3 setup.py develop

Direction

Not a full PyTorch clone

EasyFHE keeps the tensor pieces that encrypted programs need and removes the rest. The result should be smaller, easier to audit, and better shaped for FHE systems research.

  • Keep tensor storage, dispatch, CUDA runtime, and FHE ops.
  • Keep selected profiling and NCCL-oriented runtime pieces.
  • Remove neural-network, optimizer, export, mobile, and quantized surfaces.
  • Make `easyfhe` the primary user-facing import path.
