Wheel Policy

EasyFHE follows a PyTorch-like release shape: one package name, separate CUDA channels, and manylinux wheels for modern Ubuntu systems.

One package name

Users install `easyfhe`. CUDA selection happens through the wheel channel instead of package names like `easyfhe-cu132`.

CUDA channels

Each CUDA runtime gets its own wheel index. The first two channels are CUDA 13.2 and CUDA 12.4.

Ubuntu coverage

The current baseline is `manylinux_2_28_x86_64`, suitable for the Ubuntu 22.04 and 24.04 line.

Publish Flow

The page is static, so releases are easy to audit. Build wheels, upload assets, update the matrix, then test a fresh install.

1

Build the wheel matrix

Use the manylinux build scripts to create CUDA-specific wheels under `wheelhouse/`.

2

Upload release assets

Put the large `.whl` files on GitHub Releases or a stable download domain. Do not commit them to `docs/`.

3

Update the install matrix

Edit `docs/install-matrix.json` and the tiny wheel index pages under `docs/whl/`.

4

Test from a clean venv

Install from the public page URL before announcing the release.

CUDA_VERSIONS="12.4 13.2" \
PYTHON_TAG=cp312-cp312 \
TORCH_CUDA_ARCH_LIST=8.0 \
