GPU accelerated encrypted tensor computation

EasyFHE

A PyTorch-derived runtime shaped around Fully Homomorphic Encryption: tensor-style Python, native CKKS material generation, CUDA FHE kernels, rotations, rescaling, and bootstrapping.

Install

Choose a CUDA wheel channel

EasyFHE keeps one Python package name and separates CUDA variants by wheel channel. The v0.1.1 wheels target Linux x86_64, Python 3.12, and Ubuntu 22.04/24.04 systems with a compatible NVIDIA driver and CUDA runtime.

Runtime

Tensor infrastructure, narrowed for FHE

FHE frontend

`easyfhe.fhe` exposes context specs, ciphertext state, plaintext preparation, arithmetic, rotation, rescale, fused ops, and bootstrapping entry points.

Native material

CKKS contexts, ciphertext material, and rotation keys can be generated through the native EasyFHE path, including fast development modes for iteration.

CUDA kernels

Native kernels cover encoding, NTT, automorphism, key switching, modulus movement, ciphertext arithmetic, and bootstrapping.
