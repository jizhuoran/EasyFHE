# ResNet20 AESPA Weights

`resnet20_aespa_weights.npz` is a single `name -> numpy.ndarray`
artifact for the packed weight, bias, and mask vectors used by
`examples/resnet/src/resnet20_aespa.py`.

It is generated by:

```bash
python examples/resnet/tools/build_resnet20_aespa_raw_npz.py
```

The NPZ contains two groups of arrays:

- All existing `examples/resnet/weights_aespa_20/*.bin` files, keyed by file stem.
- Generated plaintext vectors that do not exist as `.bin` files.

Generated keys currently include:

- `fc_4096`
- `bias_4096`
- `mask_from_to_0_1024_16384`
- `mask_first_n_16384_32768`
- `mask_second_n_16384_32768`
- `mask_first_n_8192_16384`
- `mask_second_n_8192_16384`
- `gen_mask_{2,4,8}_32768`
- `gen_mask_{2,4}_16384`
- `mask_first_n_mod_16_1024_{0..15}_32768`
- `mask_first_n_mod2_8_256_{0..31}_16384`
- `mask_channel_{0..31}_16_1024`
- `mask_channel_{0..63}_32_256`
- `mask_mod_64_0.015625_4096`
- `slot_conversion_mask_32768to8192`
- `slot_conversion_mask_16384to4096`

The artifact is intentionally unencoded: it contains packed numeric vectors only.
It does not contain `PreparedPlaintext` or encoded FHE plaintext objects.
